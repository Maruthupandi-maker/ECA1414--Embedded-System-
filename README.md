## 🧪 Experiments

- **EXP1** — Arduino UNO-Based Smart Home Safety and Occupancy Monitoring System using Gas, PIR and Ultrasonic Sensors
- **EXP2** — Formal Design of an Embedded Controller using State Machine (Statechart) Modeling: Traffic Light Controller
- **EXP3** — I²C-Based Health Monitoring Node for Pulse and Temperature Acquisition
- **EXP4** - LM35 Temperature Monitoring and PWM Control Using Arduino
